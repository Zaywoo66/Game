# Visual and playable UI scope

Visual design, layout, reusable components and map overlays are governed by
[`UI_DESIGN_GUIDE.md`](UI_DESIGN_GUIDE.md). If guidance conflicts, the design
guide takes precedence for those visual concerns.

Interaction semantics remain governed by the applicable milestone files and
`DECISIONS.md`. This repository did not contain a shared
`VISUAL_AND_UI_SPEC.md` when the design guide was added; this file records the
scope boundary without importing unreviewed assumptions from an external copy.
